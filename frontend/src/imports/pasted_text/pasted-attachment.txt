Actúa como un diseñador/desarrollador frontend senior especializado en e-commerce 
y experiencias de marca premium. Necesito que generes el frontend completo para 
"Nails Studio", una PYME de nail art con posicionamiento premium/artístico 
(NO rosa pastel genérico de plantilla, sino un estudio de diseño de uñas de alto nivel).

CONTEXTO DEL NEGOCIO
Categorías de servicio:
- Set de uñas Acrílicas
- Set de Gel X
- Esmaltado semipermanente (manos y pies)
- Pedicure spa
- Relieves
- Encapsulados
- Efectos
- Mano alzada

IMPORTANTE: Las clientas NO tienen cuenta ni login. Solo existe login para el 
Admin (la dueña), que usa el sistema para mantenimiento del catálogo, agenda 
y clientas.

DIRECCIÓN DE DISEÑO
- Paleta base sofisticada (negro/beige/terracota, a elegir) + un acento vibrante 
  para CTAs.
- Tipografía serif elegante para títulos (ej. Playfair Display) + sans-serif 
  limpia para texto (ej. Inter).
- Storytelling visual: cada categoría de servicio debe tener una identidad 
  visual sutil propia (ícono o tono de color distintivo) para diferenciarse 
  dentro del catálogo.
- Catálogo con estética tipo feed de Pinterest/Instagram: fotos grandes, 
  buen espaciado, nada de cards genéricas de e-commerce.
- Mobile-first.

ESTRUCTURA Y PÁGINAS

1. HOME
   - Hero con imagen/video de trabajos destacados + CTA "Reservar cita"
   - Grid de las 8 categorías de servicio
   - Sección "Diseños del mes / Tendencias" (curada, rotativa)
   - Preview de galería antes/después
   - Testimonios
   - Preview de ubicación + horario (con estado dinámico Abierto/Cerrado)
   - Footer con redes sociales y contacto rápido

2. CATÁLOGO
   - Grid de diseños/servicios con filtros combinables por:
     * Categoría (las 8 mencionadas)
     * Ocasión (Boda, Diario, Fiesta/Evento, Minimalista)
     * Complejidad/tiempo (Express vs Elaborado)
   - Buscador
   - Cada card: imagen, nombre, categoría, precio "desde $X", duración estimada
   - Comparador visual: permitir seleccionar 2-3 diseños y verlos lado a lado
   - Detalle de producto: galería de imágenes, descripción, técnica, precio, 
     duración, botón "Reservar este diseño"

3. RESERVAS
   - Flujo: selección de servicio → fecha/hora disponible → datos de contacto 
     → confirmación
   - Sección especial "Reserva para eventos" (bodas, XV años, grupos) con 
     formulario diferenciado (más campos: cantidad de personas, fecha del evento)

4. GALERÍA
   - Grid filtrable por categoría, formato antes/después
   - Modal/lightbox al hacer click

5. BLOG
   - Listado de artículos/tips de cuidado de uñas
   - Vista de artículo individual
   - Puede alimentar SEO y posicionar a la dueña como experta

6. NOSOTROS
   - Historia del negocio
   - Fotos de la dueña trabajando (estilo detrás de cámaras, generando 
     cercanía y confianza)

7. CONTACTO / UBICACIÓN
   - Formulario de contacto (nombre, email, teléfono, mensaje)
   - Mapa embebido + botón directo a Google Maps/Waze
   - Horario de atención con indicador dinámico "Abierto ahora" / 
     "Cerrado, abrimos a las [hora]"
   - Fotos de la dueña trabajando en el local

8. PROGRAMA DE REFERIDOS Y GIFT CARDS
   - Página/sección explicando cómo funciona el programa de referidos 
     (ej. código único para compartir)
   - Sección de compra de gift cards digitales (monto, mensaje personalizado, 
     envío por email)

9. LOGIN ADMIN (único login del sitio)
   - Acceso solo para la dueña/staff

10. DASHBOARD ADMIN
    - Gestión de catálogo (CRUD de servicios/diseños por categoría)
    - Calendario de citas con colores por tipo de servicio
    - Gestión de clientas: ficha con historial visual de diseños realizados, 
      sistema de puntos/fidelidad, opción de "repetir último diseño" 
      (gestionado desde el admin al agendar)
    - Recordatorios automáticos de retoque (2-3 semanas post-servicio) 
      para contactar a la clienta
    - Control de inventario básico (alertas de stock bajo)
    - Métricas: servicios más solicitados, ingresos estimados, ocupación 
      semanal, clientas inactivas
    - Gestión de gift cards emitidas y código de referidos

11. CHATBOT (flotante, global en todas las páginas)
    - Flujo guiado con botones rápidos: "Ver precios", "Agendar cita", 
      "Ubicación y horario", "Quiero que me recomienden un diseño"
    - Modo "asesor de diseño": mini-quiz (ocasión, color favorito, nivel de 
      mantenimiento deseado) que termina mostrando 2-3 diseños del catálogo 
      con imagen incluida directamente en el chat
    - Diseño visual consistente con la identidad de marca

REQUISITOS TÉCNICOS
- Responsive completo (mobile, tablet, desktop)
- Componentes reutilizables (cards de producto, botones, modales, badges 
  de categoría, filtros)
- Estados de carga y vacío bien diseñados
- Accesibilidad básica (contraste, alt en imágenes, navegación por teclado)
- Animaciones sutiles en hover/transiciones
- PROHIBIDO usar alert(), confirm() o prompt() nativos del navegador. Toda 
  confirmación, notificación o mensaje al usuario debe mostrarse mediante 
  modales/diálogos diseñados a medida, coherentes con la identidad visual 
  de la marca (tipografía, colores, bordes redondeados, animación de 
  entrada/salida suave). Esto aplica a:
  * Confirmación de reserva exitosa
  * Errores de formulario (contacto, reserva, login admin)
  * Confirmación de eliminación/edición en el Dashboard Admin
  * Notificación de "diseño agregado al comparador"
  * Cualquier feedback del chatbot o del quiz de asesor de diseño
  * Toasts no intrusivos para acciones rápidas (ej. "copiado el código de 
    referido"), reservando modales centrados para acciones que requieren 
    confirmación o atención del usuario

ENTREGABLE
Genera primero el sistema de diseño (paleta, tipografía, componentes base) 
y la navegación general, luego construye cada página en este orden: 
Home → Catálogo → Reservas → Dashboard Admin → resto de páginas.
